# 运动打卡小程序

## 项目介绍

本项目是一个基于微信小程序的运动打卡应用，旨在帮助用户养成良好的运动习惯，通过积分制度和红包惩罚机制激励用户坚持运动。

## 功能特点

### 1. 运动打卡
- 支持多种运动类型：跑步、跳绳、keep运动、羽毛球、游泳、徒步等
- 每种运动有对应的积分计算规则
- 上传运动截图作为凭证
- 添加备注信息

### 2. 积分规则
- 跑步1公里为15分
- 跳绳或keep运动5分钟为10分
- 羽毛球1小时为70分；游泳1千米70分
- 徒步每10000步算25分
- 拍一拍奖励1分，每天最多可获得1分
- 轻量运动一分钟1分，重量运动一分钟1.5分

### 3. 特殊规则
- 单日不足20分记为0分，单日上限70分
- 每周需至少获得180运动分，不足180分按差额发红包（1分=1元钱）
- 女生生理期或特殊原因（如生病等）可申请免处罚

### 4. 统计功能
- 周统计：显示本周累计分数和目标完成进度
- 打卡记录：查看历史打卡记录
- 红包计算：自动计算未达标需要发放的红包金额

## 使用说明

1. 首页：显示本周打卡进度和最近打卡记录
2. 打卡页：选择运动类型，输入运动量，上传截图完成打卡
3. 统计页：查看本周统计数据，计算是否需要发红包
4. 我的页：个人信息和设置

## 开发环境

- 微信开发者工具
- 小程序基础库版本：2.19.4

## 注意事项

- 本小程序仅在微信环境中运行
- 打卡数据存储在本地，清除缓存会导致数据丢失
- 红包功能需要接入微信支付API（当前版本仅做模拟展示）
